## 第一阶段：最小可用 MVP（1~2 周，单人可完成）

### 🎯 目标

在本地，用户能通过 **命令行** 或 **Swagger UI** 提问，系统从指定 Git 仓库中找到相关代码，并给出带**可追踪来源**的回答（即使前端暂不展示，日志中也要能看到出处）。

### 技术栈

- **前端**：命令行交互（Python `input()` 或 FastAPI 自带的 Swagger UI `/docs`）
- **接入层**：前端直连 Python 服务
- **后端**：由 FastAPI 全权处理
- **Python AI 服务**：
  - FastAPI（`/chat` 接口）
  - Chroma（向量库，本地持久化）
  - LangChain（仅使用 RAG 链，暂不引入 Agent）
- **数据库**：SQLite 可选（本阶段不强制，先忽略）
- **LLM**：本地 阿里云百炼qwen3-max API（from langchain_community.chat_models import ChatTongyi）

### 📝 核心流程（仅 RAG）

```
用户输入问题 
  ↓ 
FastAPI 接收 
  ↓ 
Chroma 检索 Top-3 代码片段 
  ↓ 
构建 Prompt（问题 + 检索片段） 
  ↓ 
LLM 生成答案 
  ↓ 
返回文本 + **控制台打印引用来源（文件路径、行号）**
```

### 🔨 具体实施步骤（含关键优化）

#### 1. 代码向量化入库（离线脚本）

**避免粗暴切分函数**  
使用**简单的函数/类边界识别**（基于正则匹配 `def`、`class`、`function` 等关键字）对代码进行预分割，再交给 `RecursiveCharacterTextSplitter` 做细粒度切分，防止将函数拦腰截断。

```python
# scripts/index_repo.py
import os
import re
from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import OllamaEmbeddings

# 简易的代码块分割器（按函数/类头部分割）
def split_by_code_blocks(content: str, file_ext: str):
    patterns = {
        ".py": r"\n(?=def |class )",
        ".java": r"\n(?=public |private |protected |class |interface )",
        ".js": r"\n(?=function |class |const |let |var )",
        ".ts": r"\n(?=function |class |interface |export )",
    }
    pattern = patterns.get(file_ext)
    if pattern:
        return re.split(pattern, content)
    else:
        return [content]

def index_repo(repo_path: str, persist_dir: str = "./chroma_db"):
    all_chunks = []
    for root, _, files in os.walk(repo_path):
        for file in files:
            if file.endswith(('.py', '.java', '.js', '.ts', '.go', '.md')):
                file_path = os.path.join(root, file)
                loader = TextLoader(file_path, encoding='utf-8')
                docs = loader.load()
                
                # 先按函数/类边界粗分
                for doc in docs:
                    ext = os.path.splitext(file)[1]
                    blocks = split_by_code_blocks(doc.page_content, ext)
                    for block in blocks:
                        if block.strip():
                            # 细粒度切分（保持上下文重叠）
                            splitter = RecursiveCharacterTextSplitter(
                                chunk_size=800, 
                                chunk_overlap=100
                            )
                            chunks = splitter.create_documents(
                                [block], 
                                metadatas=[{"source": file_path}]
                            )
                            all_chunks.extend(chunks)

    # 向量化入库
    embeddings = OllamaEmbeddings(
        model="nomic-embed-text",
        num_ctx=4096,           # 防止超长文本
        request_timeout=60.0    # 防止索引中断
    )
    vectordb = Chroma.from_documents(
        all_chunks, 
        embeddings, 
        persist_directory=persist_dir
    )
    vectordb.persist()
    print(f"✅ 索引完成，共 {len(all_chunks)} 个片段")

if __name__ == "__main__":
    index_repo("/path/to/your/git/repo")
```

#### 2. 问答 API 服务（单文件 FastAPI）

**日志中打印引用来源，方便调优**  
`RetrievalQA` 默认只返回答案文本，但我们可以通过 `return_source_documents=True` 获取来源并在控制台打印，验证检索质量。

```python
# app.py
import logging
from fastapi import FastAPI
from pydantic import BaseModel
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import OllamaEmbeddings
from langchain_community.llms import Ollama
from langchain.chains import RetrievalQA

logging.basicConfig(level=logging.INFO)
app = FastAPI()

# 初始化向量库与模型
vectordb = Chroma(
    persist_directory="./chroma_db",
    embedding_function=OllamaEmbeddings(model="nomic-embed-text")
)
llm = Ollama(
    model="qwen2.5:7b",
    temperature=0.1,
    request_timeout=120.0
)

# 关键参数：return_source_documents=True
qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    retriever=vectordb.as_retriever(search_kwargs={"k": 3}),
    return_source_documents=True
)

class Query(BaseModel):
    question: str

@app.post("/chat")
def chat(query: Query):
    result = qa_chain.invoke(query.question)
    answer = result["result"]
    sources = result["source_documents"]
    
    # 👇 在控制台打印来源（调试用，后续可扩展至前端）
    for i, doc in enumerate(sources):
        src = doc.metadata.get("source", "unknown")
        logging.info(f"📎 引用 {i+1}: {src} (片段长度: {len(doc.page_content)})")
    
    # 当前版本仅返回文本，第二阶段再扩展前端展示引用
    return {"answer": answer}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

#### 3. 测试验证

1. 启动 Ollama 并拉取模型：
   ```bash
   ollama serve
   ollama pull qwen2.5:7b
   ollama pull nomic-embed-text
   ```

2. 索引你的代码仓库：
   ```bash
   python scripts/index_repo.py
   ```

3. 启动 FastAPI：
   ```bash
   uvicorn app:app --reload
   ```

4. 打开浏览器访问 `http://localhost:8000/docs`，使用 Swagger UI 测试问答。

5. 观察控制台输出，确认每个问题都附带了**具体的文件来源**。

### 📌边界说明（非常重要）

| 项目         | 是否包含 | 备注                                                      |
| :----------- | :------- | :-------------------------------------------------------- |
| 多仓库切换   | ❌        | 本阶段仅索引单个仓库，第二阶段通过 Chroma Collection 实现 |
| 前端展示引用 | ❌        | 引用仅在服务器控制台打印，用于内部验证                    |
| 会话历史记忆 | ❌        | 每次提问独立处理，无上下文关联                            |
| 流式响应     | ❌        | 一次性返回完整答案                                        |
| 用户鉴权     | ❌        | 仅本地运行，无权限控制                                    |

**核心目的是：验证“检索 → 生成”链路在代码库上是否有效，并为后续扩展提供信心。**
