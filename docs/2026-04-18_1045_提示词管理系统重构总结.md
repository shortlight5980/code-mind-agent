# 提示词管理系统重构总结

**修改时间**：2026-04-18 10:45  
**修改类型**：架构重构  
**影响范围**：提示词管理、Agent模块、总结模块

## 一、修改概述

本次重构解决了项目中提示词管理不一致的问题，将散落在多个文件中的提示词统一到 `PromptManager` 单例中管理。重构采用了中期方案，实现了提示词的集中管理、版本控制和多语言支持。

## 二、解决的问题

### 1. 僵尸代码问题
- **问题**：`agent/prompts.py` 中定义了 `CODEMIND_AGENT_PROMPT` 和 `CODEMIND_AGENT_NEXT_STEP_PROMPT` 但未在任何代码中使用
- **解决**：删除 `agent/prompts.py` 文件

### 2. 硬编码提示词问题
- **问题**：
  - `agent/agent.py` 中的 `load_system_prompts()` 函数返回硬编码字符串
  - `utils/summarizer.py` 中的 `SUMMARIZER_PROMPT_TEMPLATE` 为独立全局变量
- **解决**：统一使用 `PromptManager` 获取提示词

### 3. 架构不统一问题
- **问题**：部分代码使用 `PromptManager`，部分使用硬编码，导致架构分裂
- **解决**：所有提示词都通过 `PromptManager` 管理

## 三、具体修改内容

### 1. 删除的文件
- `agent/prompts.py` - 未使用的僵尸代码

### 2. 修改的文件
- `prompts/prompt_manager.py` - 扩展 `PromptScenario` 枚举，添加新提示词
- `agent/agent.py` - 使用 `PromptManager` 替代硬编码系统提示词
- `utils/summarizer.py` - 使用 `PromptManager` 替代硬编码总结提示词

### 3. 新增功能
- **扩展提示词场景**：添加 `AGENT_SYSTEM` 和 `SUMMARIZATION` 场景
- **统一接口**：所有模块通过相同方式获取提示词
- **修复bug**：修复 `PromptManager.get_prompt()` 方法的回退逻辑

## 四、架构改进

### 1. 统一管理架构
```
重构前：
├── app.py (使用 PromptManager)
├── agent/agent.py (硬编码字符串)
└── utils/summarizer.py (独立 PromptTemplate)

重构后：
├── app.py (使用 PromptManager)
├── agent/agent.py (使用 PromptManager)
└── utils/summarizer.py (使用 PromptManager)
```

### 2. 提示词管理体系
```
PromptManager (单例)
├── PromptScenario (枚举)
│   ├── GENERAL_QA
│   ├── AGENT_SYSTEM
│   ├── SUMMARIZATION
│   ├── CODE_EXPLANATION
│   ├── BUG_FIX
│   └── ARCHITECTURE_DESIGN
├── PromptLanguage (枚举)
│   ├── ZH_CN
│   └── EN_US
└── PromptVersion (数据类)
    ├── version
    ├── scenario
    ├── language
    ├── template
    ├── input_variables
    └── description
```

### 3. 技术特性
- **单例模式**：确保全局只有一个 `PromptManager` 实例
- **版本控制**：支持提示词版本管理，便于更新和维护
- **多语言支持**：保持中英文支持能力
- **易于扩展**：新增场景只需扩展 `PromptScenario` 枚举
- **配置灵活**：可通过 `add_custom_prompt()` 动态添加自定义提示词

## 五、代码变化示例

### 1. Agent系统提示词获取
```python
# 重构前 (agent/agent.py)
def load_system_prompts() -> str:
    return """你是 CodeMind Agent，一个专业的代码仓库智能助手..."""

# 重构后 (agent/agent.py)
def load_system_prompts() -> str:
    prompt_manager = PromptManager.get_instance()
    prompt_template = prompt_manager.get_prompt(
        scenario=PromptScenario.AGENT_SYSTEM,
        language=PromptLanguage.ZH_CN
    )
    return prompt_template.template
```

### 2. 总结提示词获取
```python
# 重构前 (utils/summarizer.py)
SUMMARIZER_PROMPT_TEMPLATE = PromptTemplate(...)

def summarize_context(question, raw_context, summarizer_llm):
    prompt = SUMMARIZER_PROMPT_TEMPLATE.format(...)

# 重构后 (utils/summarizer.py)
def get_summarizer_prompt_template() -> PromptTemplate:
    prompt_manager = PromptManager.get_instance()
    return prompt_manager.get_prompt(
        scenario=PromptScenario.SUMMARIZATION,
        language=PromptLanguage.ZH_CN
    )

def summarize_context(question, raw_context, summarizer_llm):
    prompt_template = get_summarizer_prompt_template()
    prompt = prompt_template.format(...)
```
