# 2026-04-17 19:11 - ReadFile 智能搜索与总结模型优化

## 概述

本次修改完善了 ReadFile 工具的用户体验，增加了文件名智能搜索功能；同时将总结模型切换为 qwen-turbo，提升系统响应速度。

---

## 主要变更

### 一、ReadFile 工具增强（agent/tools/read_file.py）

#### 新增文件名智能搜索功能

当用户传入的文件路径不存在时，工具会自动提取文件名进行搜索，并根据匹配结果智能处理：

| 搜索结果 | 处理方式 |
|---------|---------|
| **无匹配** | 返回原错误信息："[错误] 读取文件失败: 文件不存在: xxx" |
| **单个匹配** | 自动读取找到的文件，返回文件内容 |
| **多个匹配** | 返回提示信息，列出所有找到的文件路径 |

#### 新增辅助函数

| 函数 | 功能 |
|------|------|
| `should_ignore_dir()` | 判断是否应该忽略的目录（.git、__pycache__ 等） |
| `should_ignore_file()` | 判断是否应该忽略的文件（.pyc、.zip 等） |
| `search_file_by_name()` | 在允许的目录中搜索指定文件名 |
| `_read_file_with_lines()` | 内部辅助函数：读取文件内容并处理行号范围 |

#### 核心搜索逻辑

```python
# 文件不存在，尝试搜索文件名
file_name = os.path.basename(file_path)
matches = search_file_by_name(file_name, allowed_dirs)

if not matches:
    return f"[错误] 读取文件失败: 文件不存在: {file_path}"
elif len(matches) == 1:
    # 自动读取找到的文件
    return _read_file_with_lines(found_path, start_line, end_line)
else:
    # 列出所有匹配文件
    result = "存在多个同名文件，请传入相对路径！\n\n找到的文件:\n"
    for i, match in enumerate(matches, 1):
        result += f"{i}. {match}\n"
    return result
```

#### 用户体验提升

**使用场景示例**：
- 用户输入：`read_file.py`（非完整路径）
- 系统自动搜索并读取：`agent/tools/read_file.py`
- 若有多个同名文件，提示用户选择

### 二、总结模型优化（config.yml）

#### 模型切换

将 summarizer 模型从 `qwen-max` 切换为 `qwen-turbo`：

```yaml
summarizer:
  model: "qwen-turbo"    # 从 qwen-max 改为 qwen-turbo
  temperature: 0.1
```

#### 优化目的

| 优化项 | 说明 |
|--------|------|
| **响应速度** | qwen-turbo 推理速度更快，降低用户等待时间 |
| **成本效率** | turbo 版本 API 调用成本更低 |
| **适用场景** | 总结任务对模型能力要求相对较低，turbo 足以胜任 |

## 架构变更

### ReadFile 工具流程图

```
用户传入文件路径
    ↓
文件是否存在？
    ├─ 是 → 安全验证 → 读取文件 → 返回内容
    └─ 否 → 提取文件名 → 搜索同名文件
                ↓
          搜索结果数量？
              ├─ 0 → 返回文件不存在错误
              ├─ 1 → 安全验证 → 读取找到的文件 → 返回内容
              └─ ≥2 → 返回提示 + 文件列表
```

## 关键技术决策

| 决策 | 说明 |
|------|------|
| **智能搜索** | 提升用户体验，无需记住完整路径 |
| **安全优先** | 搜索到文件后仍需经过安全验证 |
| **模糊匹配** | 仅匹配文件名，不匹配路径，降低复杂度 |
| **qwen-turbo** | 总结任务用轻量模型，提升响应速度 |
| **代码复用** | 将读取逻辑提取为 _read_file_with_lines() |
