## 使用说明

### 方式一：使用配置文件（推荐）

1. 在 `config.yml` 中设置仓库路径：
```yaml
repo:
  path: "/path/to/your/repo"
```

2. 直接运行索引脚本，无需参数：
```bash
python scripts/index_repo.py
```

### 方式二：命令行指定路径（覆盖配置）

即使配置文件中设置了路径，也可以通过命令行参数覆盖：

```bash
python scripts/index_repo.py /other/path/to/repo
```

### 方式三：索引当前项目（默认）

如果 `config.yml` 中 `repo.path` 为 `"."` 或未设置，默认索引当前项目：

```bash
python scripts/index_repo.py
```
