# 01. 项目总览

## 什么是 CodeMind Agent？

CodeMind Agent 是一个**代码仓库智能问答系统**。简单来说，它就像一个对你的代码库非常熟悉的助手，你可以用自然语言问它关于代码的问题，它会基于代码库的内容给出准确的回答。

### 举个例子

假设你有一个 Python 项目，你可以这样问：

> **你**：这个项目的主要功能是什么？
> 
> **CodeMind Agent**：根据代码分析，这是一个待办事项管理系统，主要功能包括：
> 1. 用户可以添加、删除、标记完成待办事项
> 2. 数据存储在 SQLite 数据库中
> 3. 提供了 RESTful API 接口
> 
> 参考来源：`app.py`、`database.py`

## 第一阶段 MVP 目标

MVP（Minimum Viable Product，最小可行产品）是指能够展示核心价值的最简单版本。

本阶段我们要实现：

✅ 用户可以通过命令行或网页（Swagger UI）提问  
✅ 系统从指定的 Git 仓库中找到相关代码  
✅ 给出带有可追踪来源的回答（告诉你答案来自哪些文件）  

## 核心流程图

```
用户输入问题
    ↓
FastAPI 接收请求
    ↓
Chroma 向量库检索相关代码片段（Top 3）
    ↓
把问题 + 检索到的代码组合成 Prompt
    ↓
调用阿里云百炼 Qwen 大模型
    ↓
返回答案 + 引用来源
```

## 这个项目适合谁学习？

- 🎓 **AI 初学者**：想了解如何把大模型应用到实际场景
- 💻 **开发者**：想学习 RAG（检索增强生成）技术
- 📚 **学习者**：想了解 FastAPI、向量数据库等现代 AI 工具
