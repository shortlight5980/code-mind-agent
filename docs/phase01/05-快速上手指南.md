# 05. 快速上手指南

本文档将手把手带你运行项目，从零开始完成一次完整的问答。

## 前置检查清单

在开始之前，请确认你已经具备：

- [ ] Python 3.9 或更高版本
- [ ] conda 已安装（用于管理环境）
- [ ] 阿里云百炼 API Key（如果没有，先去 https://bailian.console.aliyun.com/ 申请）
- [ ] 一个代码仓库（用于测试，比如你自己的一个小项目）

---

## 第一步：环境准备

### 1.1 激活 conda 环境

```bash
conda activate AI
```

如果还没有创建 `AI` 环境，可以这样创建：

```bash
conda create -n AI python=3.10
conda activate AI
```

### 1.2 安装依赖

```bash
cd C:\Users\14144\Desktop\CodeMindAgent
pip install -r requirements.txt
```

**可能遇到的问题**：

| 问题 | 解决方案 |
|------|----------|
| 下载速度慢 | 用清华源：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 某个包安装失败 | 单独安装失败的包，看具体错误信息 |

---

## 第二步：配置 API Key

### 2.1 创建 .env 文件

```bash
# 复制模板
cp .env.example .env
```

或者手动创建一个 `.env` 文件，内容如下：

```
DASHSCOPE_API_KEY=你的API_KEY
CHROMA_PERSIST_DIR=./chroma_db
```

### 2.2 填入你的 API Key

编辑 `.env` 文件，把 `你的API_KEY` 替换成你真实的阿里云百炼 API Key。

**⚠️ 注意**：
- API Key 不要提交到 Git！`.gitignore` 已经包含了 `.env`
- 如果不小心提交了，立即去阿里云控制台重新生成 Key

## 第五步：测试问答（三种方式任选）

### 方式一：Swagger UI（推荐，最简单）

1. 打开浏览器，访问：http://localhost:8000/docs

2. 你会看到一个漂亮的 API 文档页面

3. 找到 `/chat` 接口，点击展开

4. 点击 **"Try it out"** 按钮

5. 在 Request body 中输入：
   ```json
   {
     "question": "这个项目的主要功能是什么？"
   }
   ```

6. 点击 **"Execute"** 按钮

7. 查看响应！

### 方式二：curl 命令

打开一个新的终端窗口（不要关闭运行服务的那个），输入：

```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d "{\"question\": \"这个项目的主要功能是什么？\"}"
```

注意：Windows 的 cmd 中引号需要转义，PowerShell 可以用单引号：

```powershell
curl -X POST http://localhost:8000/chat `
  -H "Content-Type: application/json" `
  -d '{"question": "这个项目的主要功能是什么？"}'
```

### 方式三：Python 脚本

创建一个 `test.py` 文件：

```python
import requests

response = requests.post(
    "http://localhost:8000/chat",
    json={"question": "这个项目的主要功能是什么？"}
)
result = response.json()

print("=" * 60)
print("回答:", result["answer"])
print("=" * 60)
print("来源:")
for i, s in enumerate(result["sources"]):
    print(f"  [{i+1}] {s['source']}")
```

然后运行：

```bash
python test.py
```

## 常见问题排查

### Q: 索引时报错 "No module named 'xxx'"

**A**: 依赖没安装全，重新运行：
```bash
pip install -r requirements.txt
```

### Q: 启动服务时提示 "服务未初始化"

**A**: 可能是向量库不存在，先运行索引脚本：
```bash
python scripts/index_repo.py C:\path\to\your\repo
```

### Q: API 调用报错 "Invalid API Key"

**A**: 检查 `.env` 文件中的 `DASHSCOPE_API_KEY` 是否正确。

### Q: 回答质量不好怎么办？

**A**: 可以尝试：
1. 问更具体的问题
2. 检查引用来源是否相关
3. 调整 `k` 值（在 `app.py` 中修改 `similarity_search` 的第二个参数）

### Q: 如何停止服务？

**A**: 在运行服务的终端按 `Ctrl + C`。
