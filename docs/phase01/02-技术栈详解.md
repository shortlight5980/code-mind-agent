# 02. 技术栈详解

本文档将详细介绍项目中使用的每个技术组件，帮助你理解它们的作用和为什么选择它们。

## 技术栈清单

| 技术/库 | 用途 | 简介 |
|---------|------|------|
| FastAPI | Web 框架 | 用于构建 API 服务 |
| Uvicorn | ASGI 服务器 | 运行 FastAPI 应用 |
| LangChain | LLM 应用框架 | 简化大模型应用开发 |
| Chroma | 向量数据库 | 存储和检索代码向量 |
| DashScope | 阿里云百炼 | 提供嵌入模型和 LLM |
| python-dotenv | 环境变量管理 | 管理 API Key 等配置 |
| Pydantic | 数据验证 | 验证 API 请求/响应数据 |

## 1. FastAPI - Web 框架

### 什么是 FastAPI？

FastAPI 是一个现代、快速（高性能）的 Python Web 框架，用于构建 API。

### 为什么选择 FastAPI？

- ⚡ **性能极高**：基于 Starlette 和 Pydantic，性能与 Node.js 或 Go 相当
- 📝 **自动生成文档**：自带 Swagger UI，浏览器中直接测试 API
- ✅ **数据验证**：基于 Pydantic，自动验证请求数据格式
- 🎯 **类型提示**：完整支持 Python 类型提示，代码更易读

### 在本项目中的作用

- 提供 `/chat` 接口：接收用户问题，返回 AI 回答
- 提供 `/health` 接口：健康检查
- 提供自动生成的 API 文档页面：`/docs`

### 简单示例

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def hello():
    return {"message": "Hello World"}
```

## 2. Uvicorn - ASGI 服务器

### 什么是 Uvicorn？

Uvicorn 是一个 ASGI（Asynchronous Server Gateway Interface，异步服务器网关接口）服务器，用于运行 Python Web 应用。

### ASGI vs WSGI？

- **WSGI**：传统的同步接口，一次只能处理一个请求
- **ASGI**：异步接口，支持并发处理多个请求，性能更好

### 在本项目中的作用

启动 FastAPI 应用，让它能够接收 HTTP 请求。

### 简单示例

```bash
# 命令行运行
uvicorn app:app --reload
```

或在代码中：

```python
import uvicorn

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 3. LangChain - LLM 应用框架

### 什么是 LangChain？

LangChain 是一个用于开发大语言模型（LLM）应用的框架。它提供了很多现成的组件和工具，让你不用从零开始构建 LLM 应用。

### 核心概念

| 概念 | 说明 |
|------|------|
| **LLM** | 大语言模型，如 GPT-4、Qwen 等 |
| **Embedding** | 嵌入模型，把文本转换成向量 |
| **Vector Store** | 向量数据库，存储和检索向量 |
| **Chain** | 链，把多个步骤组合起来 |

### 在本项目中的作用

虽然我们在 `app.py` 中没有使用 LangChain 的复杂链（为了简化），但我们使用了它的以下组件：

- `DashScopeEmbeddings`：调用阿里云的嵌入模型
- `Chroma`：向量数据库的集成
- `ChatTongyi`：调用阿里云的 Qwen 大模型

## 4. Chroma - 向量数据库

### 什么是向量数据库？

在理解向量数据库之前，先理解几个概念：

#### 什么是向量（Vector）？

向量就是一组数字，例如：`[0.123, -0.456, 0.789, ...]`。

#### 什么是嵌入（Embedding）？

嵌入是把文本转换成向量的过程。语义相似的文本，它们的向量在数学空间中也会更接近。

```
"猫咪" → [0.2, 0.8, 0.1, ...]
"小狗" → [0.25, 0.75, 0.15, ...]  ← 和"猫咪"很接近
"飞机" → [0.9, -0.1, 0.3, ...]     ← 和前两个差很远
```

#### 什么是向量数据库？

普通数据库存储的是表格、JSON 等数据。向量数据库专门存储向量，并支持**相似度搜索**。

### 为什么需要向量数据库？

假设你有 1000 个代码文件，用户问了一个问题。你不可能把所有代码都发给 LLM（太长了），所以需要：

1. 把所有代码片段转换成向量，存入向量数据库
2. 用户提问时，把问题也转换成向量
3. 在向量数据库中找到和问题最相似的几个代码片段
4. 只把这几个片段发给 LLM

这就是 **RAG（检索增强生成）** 的核心思想！

### 在本项目中的作用

- 存储代码片段的向量
- 根据用户问题检索最相关的代码片段

## 5. DashScope (阿里云百炼)

### 什么是阿里云百炼？

阿里云百炼是阿里云提供的 AI 模型服务平台，提供各种预训练模型。

### 我们使用的模型

| 模型 | 用途 | 说明 |
|------|------|------|
| `text-embedding-v3` | 嵌入模型 | 把文本转换成向量 |
| `qwen-max` | 大语言模型 | 理解问题并生成回答 |

### API Key

使用阿里云百炼需要申请 API Key，通过环境变量 `DASHSCOPE_API_KEY` 配置。

## 6. python-dotenv - 环境变量管理

### 什么是环境变量？

环境变量是操作系统级别的变量，常用于存储配置信息（如 API Key、数据库密码等）。

### 为什么用 python-dotenv？

直接在代码中写 API Key 是不安全的（容易提交到 Git）。python-dotenv 可以从 `.env` 文件中读取环境变量。

### 示例

`.env` 文件：
```
DASHSCOPE_API_KEY=sk-abcdef123456
CHROMA_PERSIST_DIR=./chroma_db
```

Python 代码：
```python
from dotenv import load_dotenv
import os

load_dotenv()  # 加载 .env 文件
api_key = os.getenv("DASHSCOPE_API_KEY")
```

## 7. Pydantic - 数据验证

### 什么是 Pydantic？

Pydantic 是一个数据验证库，使用 Python 类型提示来定义数据结构。

### 为什么需要数据验证？

API 接收到的请求可能格式不正确，Pydantic 可以自动验证并给出清晰的错误信息。

### 在本项目中的作用

定义 `/chat` 接口的请求格式：

```python
from pydantic import BaseModel

class Query(BaseModel):
    question: str
```

这样，如果请求体中没有 `question` 字段，FastAPI 会自动返回错误。
