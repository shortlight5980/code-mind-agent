| 4️⃣ | [04-代码结构解析.md](./04-代码结构解析.md) | 逐行解析项目代码 | 30 分钟 |

## 🎯 学习目标

读完这些文档后，你将能够：

- ✅ 理解什么是 RAG 以及它的工作原理
- ✅ 看懂本项目的每一行代码
- ✅ 独立运行项目并进行问答测试
- ✅ 为后续扩展功能打下基础

## 💡 学习建议

1. **按顺序阅读**：文档之间有依赖关系，建议按序号阅读
2. **动手实践**：不要只看，一定要跟着 [05-快速上手指南.md](./05-快速上手指南.md) 动手运行
3. **代码对照**：读 [04-代码结构解析.md](./04-代码结构解析.md) 时，打开对应的代码文件对照看
4. **多问问题**：遇到不懂的名词，先查资料，再在代码中找它的实际用法
