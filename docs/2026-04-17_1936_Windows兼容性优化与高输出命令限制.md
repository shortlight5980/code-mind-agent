# Windows 兼容性优化与高输出命令限制

## 修改概述

本次修改主要解决了两个问题：1) Windows 系统下 YAML 配置文件路径解析错误；2) RunCommand 工具在 Windows 下无法使用的问题；3) 防止高输出命令消耗过多 Token。

---

## 主要修改内容

### 1. config.yml 路径格式修复

**问题**：YAML 文件中 Windows 路径使用反斜杠 `\` 被当作转义字符处理，导致解析错误。

**解决方案**：将 `config.yml` 第 11 行的路径从反斜杠改为正斜杠：

```yaml
# 修改前
path: "C:\Users\14144\Desktop\CodeMindAgentClient"

# 修改后
path: "C:/Users/14144/Desktop/CodeMindAgentClient"
```

正斜杠在 Windows 系统中同样被支持，且不会被 YAML 解析器当作转义字符。

---

### 2. RunCommand 工具 Windows 兼容性增强

**问题**：Windows 系统没有 `ls`、`find`、`head`、`tail`、`wc` 等 Unix 命令，导致 RunCommand 工具失效。

**解决方案**：

#### 2.1 操作系统检测与命令映射

```python
# 操作系统检测
IS_WINDOWS = sys.platform.startswith("win")

# Unix 命令到 Windows 命令的映射
WINDOWS_CMD_MAPPING = {
    "ls": ["dir"],
    "cat": ["type"],
    "grep": ["findstr"],
    "find": None,      # 使用 Python 实现
    "head": None,      # 使用 Python 实现
    "tail": None,      # 使用 Python 实现
    "wc": None,        # 使用 Python 实现
    "git": ["git"],    # git 在 Windows 上通常也可用
}

# 同时也允许直接使用 Windows 命令
WINDOWS_ALLOWED_COMMANDS = ["dir", "type", "findstr", "where"]
```

#### 2.2 智能命令转换

新增 `_normalize_command_for_windows()` 函数，将 Unix 命令参数自动转换为 Windows 等效参数：

- `ls -l` → `dir /Q`
- `ls -a` → `dir /A`
- `grep` → `findstr`
- `ls -R` → 禁止（递归参数被安全模块拦截）

#### 2.3 Python 原生实现复杂命令

对于 `find`、`head`、`tail`、`wc` 等复杂命令，直接用 Python 实现，确保跨平台行为一致：

```python
def _execute_python_command(cmd_name: str, args: list) -> str:
    if cmd_name == "find":
        # Python 实现 find 命令
        ...
    elif cmd_name == "head":
        # Python 实现 head 命令
        ...
    # ... 其他命令
```

#### 2.4 Windows shell 特殊处理

Windows 的 `dir`、`type` 等是 shell 内置命令，需要 `shell=True` 才能执行。代码中做了特殊处理：

```python
# 对于 Windows 内置命令（如 dir），需要使用 shell=True
base_cmd = args[0].lower() if args else ""
use_shell = base_cmd in ["dir", "type", "findstr"]
```

### 3. 高输出命令限制

**问题**：`ls -R`、`dir /S` 等递归命令会输出大量内容，消耗过多 Token。

**解决方案**：

#### 3.1 安全参数拦截

在 `security.py` 的 `is_command_allowed()` 函数中新增禁止参数列表：

```python
BLOCKED_ARGS = {
    "ls": ["-R", "-r", "--recursive"],
    "dir": ["/S", "/s"],
    "find": [],
}
```

#### 3.2 find 命令结果限制

Python 实现的 `find` 命令最多只返回 100 条结果：

```python
MAX_RESULTS = 100
# ... 查找逻辑 ...
if len(result) >= MAX_RESULTS:
    break

if len(result) >= MAX_RESULTS:
    output += f"\n\n[警告] 结果已截断，仅显示前 {MAX_RESULTS} 条"
```

#### 3.3 全局输出字符限制

所有命令输出最多 10000 字符，超过自动截断：

```python
MAX_OUTPUT_CHARS = 10000
if len(stdout_content) > MAX_OUTPUT_CHARS:
    stdout_content = stdout_content[:MAX_OUTPUT_CHARS] + "\n\n[警告] 输出已截断..."
```

---

### 4. 安全模块增强

`is_command_allowed()` 函数现在支持：

1. Windows 命令识别（dir、type、findstr）
2. 危险参数拦截（-R、/S 等）
3. 命令映射检查（Unix → Windows）

## 关键技术决策

1. **Python 实现替代 shell 命令**：对于跨平台差异大的命令（find、head 等），直接用 Python 实现，确保行为一致
2. **选择性使用 shell=True**：仅在 Windows 下对内置命令使用 shell=True，其他情况保持 shell=False
3. **多层输出限制**：参数禁止 + 结果数量限制 + 字符数限制，三重防护
4. **向后兼容**：Unix 系统下行为保持不变
