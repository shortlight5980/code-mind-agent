# 第二阶段：Agent 智能体功能与流式输出

## 🎯 阶段目标

在 Phase01 检索增强生成（RAG）的基础上，引入 **Agent 智能体**，使系统能够主动调用工具（读取文件、搜索代码、执行只读命令）深入探索代码库。同时增加 **流式输出** 能力，优化日志管理，并完善跨平台兼容性。

核心能力：
- ✅ 自主规划：根据用户问题决定调用哪些工具
- ✅ 工具调用：`ReadFile`、`SearchCode`、`RunCommand`
- ✅ 流式响应：边生成边返回，体验更流畅
- ✅ 安全可控：三层检查保障文件与命令安全
- ✅ 跨平台：Windows / Linux / macOS 统一可用
- ✅ 完善日志：按天切分，便于排查与学习

## 技术栈与架构

| 组件         | 技术选型                                         |
| :----------- | :----------------------------------------------- |
| 框架         | FastAPI（HTTP 服务）                             |
| Agent 编排   | LangChain 1.0 `create_agent`                     |
| LLM          | 阿里云百炼 `ChatTongyi`（qwen-max / qwen-turbo） |
| 向量检索     | Chroma（本地持久化） + `OllamaEmbeddings`        |
| 流式响应     | FastAPI `StreamingResponse` + 异步生成器         |
| 配置管理     | YAML（`config.yml`）                             |
| 操作系统适配 | `sys.platform` 检测 + Python 原生命令实现        |

### 整体架构图

```
用户请求 → FastAPI (/chat 或 /chat/stream)
                ↓
         ┌──────────────┐
         │  Chroma 检索  │  Top-7 代码片段
         └──────────────┘
                ↓
         ┌──────────────┐
         │  上下文总结    │  qwen-turbo 精炼
         └──────────────┘
                ↓
         ┌──────────────┐
         │  CodeMindAgent │  （LangChain create_agent）
         │  - ReadFile    │
         │  - SearchCode  │
         │  - RunCommand  │
         └──────────────┘
                ↓
         流式/非流式响应（含引用来源）
```

### 1.2 CodeMindAgent 类

采用面向对象设计，统一封装流式与非流式执行：

```python
class CodeMindAgent:
    def __init__(self):
        # 从配置加载模型、工具、系统提示词
    
    def execute(self, question: str, docs: list, summarizer_llm) -> str:
        """非流式执行，返回完整答案"""
    
    def execute_stream(self, question: str, docs: list, summarizer_llm):
        """流式执行，返回生成器，逐块产出内容"""
```

#### 向后兼容

原有函数式接口继续保留，内部使用 `CodeMindAgent` 类：

```python
def create_codemind_agent() -> CodeMindAgent:
    return CodeMindAgent()

def run_agent_with_summary(question, agent, docs, llm) -> str:
    return agent.execute(question, docs, llm)
```

## 二、流式输出功能

### 2.1 HTTP 接口

| 接口           | 方法 | 响应类型          | 说明                     |
| :------------- | :--- | :---------------- | :----------------------- |
| `/chat`        | POST | JSON              | 非流式（保持兼容）       |
| `/chat/stream` | POST | `text/plain` 流式 | 实时返回生成内容（新增） |

### 2.2 实现要点

```python
async def generate_stream(agent, question, docs, summarizer_llm):
    """异步生成器，逐块产出 Agent 输出"""
    for chunk in agent.execute_stream(question, docs, summarizer_llm):
        yield chunk

@app.post("/chat/stream")
async def chat_stream(request: ChatRequest):
    return StreamingResponse(
        generate_stream(agent, request.question, docs, summarizer_llm),
        media_type="text/plain"
    )
```

### 2.3 使用示例

```bash
curl -N -X POST "http://localhost:8000/chat/stream" \
  -H "Content-Type: application/json" \
  -d '{"question": "介绍一下项目结构"}'
```

## 四、工具详解

### 4.1 ReadFile – 读取文件

**路径解析策略**（按优先级尝试）：
1. 直接路径（相对于项目根目录）
2. `repo.path` 配置的仓库路径下查找
3. 绝对路径提取文件名，再到 `repo.path` 下搜索
4. 若均失败，自动进行**文件名智能搜索**

**智能搜索**：
- 若找到 **1 个**匹配 → 自动读取
- 若找到 **多个**匹配 → 返回文件列表提示用户选择
- 若无匹配 → 返回明确错误

**安全验证**：
- 路径必须在 `agent.allowed_dirs` 或 `repo.path` 白名单内
- 不得读取 `agent.blocked_files` 中的敏感文件（如 `.env`、`*.key`）

### 4.2 SearchCode – 语义搜索

基于 Chroma 向量库进行语义检索，返回与问题最相关的代码片段。支持过滤文件类型与限制返回数量。

### 4.3 RunCommand – 执行只读命令

**支持的操作系统**：Linux、macOS、Windows

**Windows 适配策略**：
1. 命令映射：`ls` → `dir`，`cat` → `type`，`grep` → `findstr`
2. 复杂命令（`find`、`head`、`tail`、`wc`）直接用 Python 原生实现，确保行为一致
3. Windows 内置命令（`dir`、`type`、`findstr`）使用 `shell=True` 执行，其余保持 `shell=False`

**安全措施**：
- 命令必须在 `agent.allowed_commands` 白名单中
- 禁止危险参数（如 `ls -R`、`dir /S`）防止大量输出
- 输出长度限制：
  - `find` 命令最多返回 100 条结果
  - 全局输出最多 10,000 字符，超出部分截断并警告

## 五、配置管理

### 5.1 config.yml 结构

```yaml
# 被索引的代码仓库路径（Agent 工具从此目录读取文件）
repo:
  path: "C:/Users/14144/Desktop/CodeMindAgentClient"   # 支持正斜杠

# 向量库配置
chroma:
  persist_directory: "./chroma_db"
  retrieval_k: 7

# 主模型配置
model:
  name: "qwen-max"
  temperature: 0.1

# 总结模型配置
summarizer:
  model: "qwen-turbo"   # 轻量模型，提升响应速度
  temperature: 0.1

# Agent 配置
agent:
  enabled: true
  model: "qwen-max"
  temperature: 0.1
  allowed_dirs: ["."]               # 路径白名单
  blocked_files: [".env", "*.key", "*.pem"]
  allowed_commands: ["ls", "cat", "grep", "find", "head", "tail", "wc", "git"]
  command_timeout: 5
  max_search_results: 50
```

### 5.2 索引脚本自动读取配置

`scripts/index_repo.py` 支持两种使用方式：

```bash
# 使用 config.yml 中配置的 repo.path
python scripts/index_repo.py

# 命令行指定路径（覆盖配置）
python scripts/index_repo.py /path/to/other/repo
```

## 六、安全设计

### 三层防护

| 层级     | 检查内容                                    | 实现位置      |
| :------- | :------------------------------------------ | :------------ |
| 路径安全 | 文件必须在 `allowed_dirs` 或 `repo.path` 内 | `security.py` |
| 文件安全 | 文件名不能匹配 `blocked_files` 黑名单模式   | `security.py` |
| 命令安全 | 基础命令在白名单内，参数不包含危险标志      | `security.py` |

### 关键实现细节

- 命令执行永远不使用 `shell=True`（Windows 内置命令除外，但已严格控制参数）
- 使用 `shlex.split()` 安全解析命令字符串
- 命令超时保护（默认 5 秒）
- 文件读取前先进行安全验证，失败则拒绝执行
