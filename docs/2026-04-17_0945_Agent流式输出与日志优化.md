# 2026-04-17 09:45 - Agent 流式输出与日志优化

## 概述

本次升级为 CodeMind Agent 项目引入了流式输出功能，优化了日志配置（按天命名），并重构了 Agent 核心模块，采用面向对象的设计模式。同时修复了索引脚本中的死循环问题。

---

## 主要变更

### 一、Agent 核心模块重构（agent/agent.py）

#### 新增 CodeMindAgent 类
将原有的函数式封装改为面向对象的类设计：

| 方法 | 功能 |
|------|------|
| `__init__()` | 初始化 Agent，配置模型、工具、提示词 |
| `execute()` | 非流式执行 Agent 任务 |
| `execute_stream()` | **流式执行 Agent 任务（新增）** |
| `_build_user_message()` | 内部辅助方法：构建用户消息 |

#### 新增 load_system_prompts() 函数
将系统提示词提取为独立函数，便于维护和复用。

#### 保留向后兼容
- `create_codemind_agent()` - 保留，内部使用 CodeMindAgent 类
- `run_agent_with_summary()` - 保留，内部使用 CodeMindAgent 类

### 二、新增流式输出功能

#### app.py 新增接口
| 接口 | 方法 | 说明 |
|------|------|------|
| `/chat` | POST | 原有非流式接口（保持兼容） |
| `/chat/stream` | POST | **新增流式接口** |

#### 流式输出生成函数
```python
async def generate_stream(
    agent: CodeMindAgent,
    question: str,
    docs: list,
    summarizer_llm: ChatTongyi
) -> AsyncGenerator[str, None]
```

使用 `StreamingResponse` 返回实时流式内容。

### 三、日志配置优化（utils/logger.py）

#### 按天命名日志文件
```python
# 获取当前日期，格式：YYYY-MM-DD
today_str = datetime.now().strftime("%Y-%m-%d")
log_filename = f"app_{today_str}.log"
```

日志文件命名示例：
- `app_2026-04-16.log`
- `app_2026-04-17.log`
- `app_2026-04-18.log`

**优点**：
- 每天一个日志文件，便于管理
- 避免单个日志文件过大
- 方便按日期查询历史日志

### 四、修复索引脚本死循环（scripts/index_repo.py）

#### 问题分析
原代码中的 `extract_python_classes_and_functions()` 和 `_split_class_by_methods()` 函数存在复杂的缩进判断逻辑，容易造成死循环。

#### 修复方案
1. **简化缩进判断**：使用 `len(curr_line) - len(stripped)` 计算缩进层数
2. **添加安全计数器**：`max_iterations = n * 2` 防止死循环
3. **简化结束判断**：只要缩进 ≤ 当前块缩进就结束
4. **添加警告日志**：当触发安全限制时输出警告

## 架构变更

### 旧架构
```
app.py → create_codemind_agent() → agent.invoke() → 一次性返回
```

### 新架构
```
app.py → CodeMindAgent 类
         ├─ execute() → 非流式，一次性返回
         └─ execute_stream() → 流式，实时返回
```

## API 变更对比

### 非流式调用（保持兼容）
```python
# 旧方式
agent = create_codemind_agent()
result = run_agent_with_summary(question, agent, docs, llm)

# 新方式（推荐）
agent = CodeMindAgent()
result = agent.execute(question, docs, llm)
```

### 流式调用（新增）
```python
# 流式输出（新增）
agent = CodeMindAgent()
for chunk in agent.execute_stream(question, docs, llm):
    print(chunk, end="")
```

### HTTP 接口

#### 非流式（原有）
```bash
POST /chat
Content-Type: application/json
{
  "question": "..."
}

Response: JSON
```

#### 流式（新增）
```bash
POST /chat/stream
Content-Type: application/json
{
  "question": "..."
}

Response: text/plain stream
```
